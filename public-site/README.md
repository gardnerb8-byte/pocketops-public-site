# PocketOps Public Site Starter

This folder contains a plain HTML/CSS starter site for PocketOps public legal
and support pages.

## Pages

- `index.html` - simple PocketOps landing page
- `privacy.html` - public-facing Privacy Policy draft
- `terms.html` - public-facing Terms of Service draft
- `account-deletion.html` - account deletion policy and instructions
- `support.html` - support/contact page
- `styles.css` - shared mobile-friendly styling

## Important

These pages are starter content only. They are not legal advice and must be
reviewed before publication or store submission.

Replace these placeholders before launch:

- `support@example.com`
- Any final support URL
- Any final privacy, terms, and account deletion URLs
- Governing law, subscription terms, limitation of liability, and processing
  time language where applicable

No build step is required. Host the files as a static site and then update the
PocketOps app/docs with the hosted URLs.
